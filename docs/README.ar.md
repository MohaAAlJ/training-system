# نظام التدريب

مرحبًا بك في مشروع نظام التدريب! هذه المنصة تساعد في إدارة طلبات التدريب، وسعة الأقسام، والمقابلات، وتقدم المتدربين.

## الميزات
- لوحة تحكم إحصائية
- إدارة المؤسسة، التخصص، القسم
- تتبع التطبيقات
- دعم متعدد اللغات (العربية، الإنجليزية، الإندونيسية)
- تبديل النمط (فاتح/داكن)

## كيفية المساهمة
1. قم بعمل Fork لهذا المستودع
2. أنشئ فرعًا للميزة (`git checkout -b feature/ميزةرائعة`)
3. قم بعمل commit للتغييرات (`git commit -m 'إضافة ميزة رائعة'`)
4. ادفع الفرع (`git push origin feature/ميزةرائعة`)
5. افتح طلب دمج (Pull Request)
