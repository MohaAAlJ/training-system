# Training System

Welcome to the Training System project! This platform helps manage internship requests, department capacity, interviews, and trainee progress.

## Features
- Dashboard with statistics
- Institution, Major, Department management
- Application tracking
- Multi-language support (English, Indonesian, Arabic)
- Theme switcher (dark/light)
