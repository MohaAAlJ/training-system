# Sistem Pelatihan

Selamat datang di proyek Sistem Pelatihan! Platform ini membantu mengelola permintaan magang, kapasitas departemen, wawancara, dan perkembangan peserta pelatihan.

## Fitur
- Dashboard statistik
- Manajemen Institusi, Jurusan, Departemen
- Pelacakan aplikasi magang
- Dukungan multi-bahasa (Indonesia, Inggris, Arab)
- Pengaturan tema (gelap/terang)

## Cara Kontribusi
1. Fork repository ini
2. Buat branch fitur (`git checkout -b fitur/FiturKeren`)
3. Commit perubahan (`git commit -m 'Tambah FiturKeren'`)
4. Push ke branch (`git push origin fitur/FiturKeren`)
5. Buka Pull Request
